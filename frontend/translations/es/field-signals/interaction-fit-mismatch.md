Un robot diseñado para pasillos de almacén se comporta diferente en un pasillo clínico. El Ajuste de Interacción mide la brecha entre donde un robot fue diseñado para operar y donde realmente lo hace.

El Ajuste de Interacción no se trata de si el robot puede navegar físicamente un nuevo entorno — la mayoría puede. Mide si las suposiciones de comportamiento del robot coinciden con las normas sociales, ritmos espaciales y expectativas humanas del sitio de despliegue. La distancia de parada, ángulo de aproximación, modulación de velocidad y tolerancia de proximidad están todas calibradas para un contexto. Cuando ese contexto cambia, la calibración no se ajusta automáticamente.

Un robot calibrado para pasillos de almacén de 2.4 metros, reubicado en un corredor clínico con la misma velocidad de aproximación, es percibido como agresivo para el personal y alarmante para los pacientes. El robot no está dañado. Su modelo de comportamiento fue desarrollado para un entorno diferente. La discordancia es una falla de Ajuste de Interacción — no una falla técnica, ni algo que una actualización de firmware solucione sin una recalibración deliberada contra el nuevo contexto.

La distinción entre bajo Ajuste de Interacción y un robot dañado es importante para la respuesta de los encargados del despliegue. Un robot dañado se repara o reemplaza. Un robot con bajo Ajuste de Interacción es tolerado — se generan quejas, se busca cómo evitarlo y finalmente se deja de usar — porque las personas que lo experimentan no pueden identificar qué está mal. “Hace que la gente se sienta incómoda” no es un ticket de servicio. Es un hallazgo en una auditoría de Ajuste de Interacción.

Los encargados del despliegue que trasladan un robot entre entornos — incluso similares — deben tratar la transición como un nuevo despliegue, no solo una reubicación. Esto significa volver a realizar la evaluación RXD de Ajuste de Interacción para el contexto receptor, recalibrar los parámetros de comportamiento y llevar a cabo un periodo de observación estructurado antes de declarar la preparación operativa. La máquina se movió. Su modelo de comportamiento no se movió con ella automáticamente.
