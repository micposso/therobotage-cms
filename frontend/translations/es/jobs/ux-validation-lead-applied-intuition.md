## Qué es el rol realmente

Applied Intuition está contratando a un Líder de Validación UX fundador para construir el puente entre los conceptos de HMI y la calidad del software en producción. El rol define la estrategia de pruebas, crea la infraestructura de validación y desarrolla un equipo enfocado en pruebas UX y HMI.

Este no es un rol convencional de investigación cualitativa. Es más parecido a un líder de validación práctico para interfaces donde la usabilidad, la automatización y la confiabilidad del producto importan porque el software está vinculado a vehículos y flujos de trabajo de autonomía.

## En qué trabajarías

- Definir métodos de validación de HMI y UX integrales para los productos de Applied
- Construir enfoques de prueba e infraestructura de automatización para la calidad de interfaces
- Convertir conceptos tempranos de HMI en superficies de producto validadas y listas para producción
- Desarrollar ingenieros de pruebas en especialistas del dominio para validación UX y HMI
- Colaborar con diseño, producto e ingeniería para cerrar brechas antes del lanzamiento

## Qué solicitan

- Experiencia validando interfaces de usuario complejas, sistemas HMI o software relevante para la seguridad
- Capacidad para diseñar estrategias de prueba y construir infraestructura práctica de validación
- Comodidad liderando trabajo práctico mientras desarrolla un equipo y un área de práctica
- Fuerte colaboración con diseñadores, ingenieros, gerentes de producto y especialistas en pruebas

## Por qué vale la pena considerarlo

La parte más interesante es el enfoque «fundacional». Applied parece estar formalizando cómo demuestra que las interfaces de autonomía son comprensibles y aptas para producción, lo cual es un nicho útil para alguien que se preocupa por la brecha entre la intención UX y la realidad operacional.
