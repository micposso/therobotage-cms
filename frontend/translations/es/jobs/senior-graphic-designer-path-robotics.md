## En qué consiste realmente el rol

Path Robotics está contratando a un diseñador gráfico senior para su función interna de marketing. El rol produce gráficos para redes sociales, hojas informativas, presentaciones, recursos web y para correo electrónico, materiales para ferias comerciales, material impreso y visualizaciones de datos para audiencias de manufactura y defensa.

El anuncio es claro en que se trata de un rol práctico e individual: la seniority proviene del juicio, la destreza y la capacidad de transformar material técnico en un diseño creíble.

## En qué trabajarías

- Diseñar hojas informativas, hojas de especificaciones, estudios de caso, materiales de ventas y folletos impresos
- Crear presentaciones para ventas, ejecutivos, conferencias y lanzamientos
- Realizar gráficos y visualizaciones de datos simples que sean precisas y coherentes con la marca
- Producir gráficos para redes sociales, recursos web, visuales para correo electrónico y materiales para ferias comerciales
- Ampliar el sistema de marca de Path para expresar de manera más clara contenido denso de robótica e industrial

## Lo que solicitan

- Dominio senior en diseño gráfico con un portafolio sólido
- Capacidad para transformar briefs, especificaciones o textos técnicos escasos en trabajos visuales pulidos
- Confort con contenido industrial, manufacturero, de defensa o técnico complejo
- Habilidad práctica para producción en digital, impresión, presentaciones y material para eventos
- Juicio para trabajar directamente con el liderazgo de marketing y entregar resultados rápidamente

## Por qué vale la pena considerarlo

El mejor marketing en robótica depende a menudo de hacer que máquinas complejas y resultados para clientes sean comprensibles sin eliminar la verdad técnica. Este rol es interesante porque Path busca un diseñador que pueda hacer que el material sobre inteligencia incorporada y automatización de soldadura sea preciso, creíble y útil para compradores comerciales.
