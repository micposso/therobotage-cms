## En qué consiste realmente el rol

Path Robotics está contratando un gerente para su Granja de Datos de Manipulación en Columbus. El rol convierte la recolección de datos de manipulación en una operación repetible, liderando operadores, programando el trabajo, gestionando la disponibilidad de equipos y entregando datos útiles de robots a los equipos de aprendizaje automático y robótica.

Es un rol de operaciones, pero con clara relevancia para la investigación del producto: esta persona es responsable del sistema de datos gestionado por humanos que determina si los modelos de manipulación reciben suficiente evidencia real de alta calidad para mejorar.

## En qué trabajarías

- Gestionar la recolección diaria de datos para sistemas robóticos de manipulación
- Liderar y entrenar a un equipo de operadores de recolección de datos
- Traducir solicitudes de datos de robótica y aprendizaje automático en planes operativos ejecutables
- Definir métricas de calidad, rendimiento, disponibilidad y entrega para las operaciones de datos

## Requisitos

- Experiencia en gestión de operaciones, equipos de producción, laboratorios o flujos de trabajo técnicos de recolección de datos
- Capacidad para trabajar estrechamente con equipos de aprendizaje automático, robótica, software y producto
- Comodidad creando procesos repetibles, planes de personal y sistemas de calidad
- Juicio práctico en torno a seguridad, preparación de equipos y ejecución bajo presión de tiempos

## Por qué vale la pena considerar esta posición

El aprendizaje robótico depende de la maquinaria poco glamorosa de la recolección de datos. Este rol es relevante porque se sitúa en la intersección donde el proceso humano, la capacidad robótica y la mejora de modelos convergen en un entorno de producción real.
