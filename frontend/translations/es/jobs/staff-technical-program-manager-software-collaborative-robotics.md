## En qué consiste realmente el rol

Collaborative Robotics está contratando un gerente de programa técnico (TPM) senior para liderar la ejecución del programa de software para Proxie. El rol abarca el software que permite al robot localizarse, percibir, navegar, comportarse en presencia de personas y operar como una flota.

Este es un rol senior de coordinación para el trabajo integrado de productos robóticos. Está diseñado para alguien que pueda crear planes, forzar claridad sobre las compensaciones y mantener la entrega de software alineada con las necesidades del robot físico.

## En qué trabajarías

- Liderar programas de software de extremo a extremo para los robots Proxie actuales y futuros
- Coordinar el trabajo de autonomía, comportamiento del robot, gestión de flotas, hardware y operaciones con clientes
- Crear planes de ejecución que equilibren alcance, tiempo, recursos y riesgos técnicos
- Mantener alineados a los líderes y a los equipos multifuncionales en las decisiones de lanzamiento

## Requisitos que piden

- Experiencia en gestión técnica de programas a nivel senior en robótica, IA o software complejo
- Capacidad para liderar programas de productos robóticos multifuncionales desde la planificación hasta la entrega
- Juicio sólido sobre dependencias de software, riesgos de lanzamiento y compensaciones entre partes interesadas
- Comodidad para trabajar en sitio con equipos de ingeniería y atención al cliente

## Por qué vale la pena considerarlo

Esta es la versión más senior de la trayectoria TPM de software en Collaborative Robotics. Lo interesante es que el software no es una plataforma abstracta; es la capa de comportamiento para un robot diseñado para compartir espacio con personas.
