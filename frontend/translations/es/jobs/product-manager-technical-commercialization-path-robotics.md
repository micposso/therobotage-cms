## Qué es realmente este rol

Path Robotics está contratando un gerente de producto para la comercialización técnica. La empresa desarrolla sistemas de soldadura robótica impulsados por IA, y este rol está diseñado para convertir capacidades complejas de robótica, IA y software en productos listos para el cliente.

El trabajo se sitúa en la capa de producto de cero a uno: descubrimiento, viabilidad, MVP, lanzamiento, adopción e iteración. La oferta menciona específicamente requisitos funcionales, de UX y a nivel de sistema para ciclos de soldadura robótica y ambientes de producción.

## En qué trabajarías

- Liderar el desarrollo de productos desde el descubrimiento inicial hasta el MVP, comercialización y lanzamiento
- Traducir capacidades de robótica, IA y software en propuestas de valor claras para el cliente
- Definir la estrategia del producto, métricas de éxito, ritmos operativos y marcos de priorización
- Representar las necesidades del cliente mediante investigación, insights de campo y flujos de trabajo de manufactura
- Colaborar con ventas, soluciones y operaciones en preparación, planificación del lanzamiento, habilitación y adopción

## Requisitos solicitados

- Experiencia en lanzar un producto nuevo (greenfield) en robótica, manufactura, automatización, IA o un dominio técnico relacionado
- Experiencia en gestión técnica de productos o comercialización técnica
- Capacidad para integrar software, hardware y datos en soluciones listas para producción
- Comodidad para tomar decisiones basadas en insights del cliente, datos de uso y experimentación
- Fuertes habilidades de facilitación entre ingeniería, ventas, operaciones y liderazgo

## Por qué vale la pena considerarlo

La soldadura robótica es una prueba valiosa del juicio en producto porque el robot debe operar bajo restricciones reales de producción. Este rol es interesante porque se trata de convertir una capacidad técnica compleja en un producto comercial reproducible, no solo de gestionar una hoja de ruta existente.
