## What the role actually is

Sample listing for local development. Internships on infrastructure tend to teach more than internships on features, and this is one of those. You work on the simulation harness the rest of the engineering team uses to validate changes before anything reaches a physical robot.

## What you would work on

- Add scenario coverage to the regression suite so more classes of failure get caught in simulation
- Cut the time it takes to run the full suite, which currently gates every merge
- Write the tooling that turns a failed real-world run into a reproducible simulated one

## What they are asking for

- Currently enrolled in an undergraduate or graduate program
- Has written enough Python to be dangerous and enough tests to be trusted
- Some exposure to ROS or a comparable robotics middleware

## Why this one is worth a look

Northgate sells its autonomy stack to other robot builders, so interns see how several different platforms fail rather than just one. That breadth is unusual this early. It is fully onsite in Boston, so factor housing into the hourly rate.
