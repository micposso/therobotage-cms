## What the role actually is

Sample listing for local development. You design and build the test stations that every unit passes through before it leaves the building. Right now that process is three engineers and a spreadsheet, and it does not survive the volume ramp that is coming.

## What you would work on

- Design end-of-line test stations for subassemblies and for the fully integrated robot
- Automate the test sequence so a technician runs it, not an engineer
- Turn test data into a feedback loop that design actually acts on

## What they are asking for

- Has built production test infrastructure, not just written test plans
- Writes Python well enough to own the test software
- Understands the difference between a test that catches defects and a test that catches yield

## Why this one is worth a look

Joining right at the pilot-to-volume transition is the most interesting moment in a hardware company and the most stressful one. Everything you build gets used immediately. Everything you skip becomes an escape.
