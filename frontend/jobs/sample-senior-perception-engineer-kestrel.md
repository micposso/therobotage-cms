## What the role actually is

Sample listing for local development. You own the perception pipeline end to end: calibration, state estimation, and the fusion layer that turns four sensor streams into one pose the planner can trust. The robot walks in aisles that change shape every shift, so a map built on Monday is wrong by Wednesday.

## What you would work on

- Tighten the visual-inertial odometry loop so drift stays under budget across a full eight-hour shift
- Rebuild the extrinsic calibration flow so a technician can run it without an engineer on site
- Decide which failures the planner should see as degraded perception rather than as a clean pose

## What they are asking for

- Shipped a perception stack on a robot that left the lab and stayed out
- Comfortable reading IMU datasheets and controller code in the same afternoon
- Has opinions about when learned components belong in a safety-relevant path

## Why this one is worth a look

Bipedal platforms in warehouses are still an open question commercially, and this is a team betting the whole product on it. The perception problem is genuinely hard and genuinely unsolved, which is the appeal. The caveat is the obvious one: the category has not yet proven it beats a wheeled base at the same task.
