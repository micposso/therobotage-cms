## What the role actually is

Path Robotics is hiring a machine learning engineer as an early member of a robot-learning team focused on whole-body loco-manipulation. The posting names visual reasoning, learned action policies, reinforcement-learning fine-tuning, and real customer data.

This is a hands-on research engineering role for precision work in heavy manufacturing. The draw is the chance to build a research stack while the problem definition is still forming.

## What you would work on

- Build learning systems for whole-body loco-manipulation and precision tasks
- Work with visual reasoning, action policies, and reinforcement learning
- Use customer data to tune and evaluate robot behavior
- Help establish the technical foundation for a new robot-learning team

## What they are asking for

- Experience in robot learning, machine learning, manipulation, or embodied AI
- Ability to build and test models that affect physical robot behavior
- Comfort with early-team ambiguity and research infrastructure work
- Interest in applying ML to industrial systems with real production stakes

## Why this one is worth a look

This is one of the more specific robot-learning postings in the current scan. Loco-manipulation for heavy manufacturing is a hard, concrete problem where better learned policies could change what industrial robots can do.
